- [ ] Informed consent forms prepared

### Data Ethics
For research involving sensitive or proprietary data:
- [ ] Data use agreements executed
- [ ] Privacy impact assessment completed
- [ ] Data anonymization procedures documented
- [ ] Secure storage and access controls implemented
- [ ] Data sharing restrictions documented

### Cybersecurity Research Ethics
For research involving vulnerability testing, penetration testing, or adversarial simulations:
- [ ] Scope limited to authorized systems only
- [ ] No unauthorized access or exploitation
- [ ] Responsible disclosure plan for discovered vulnerabilities
- [ ] Legal review completed (if applicable)
- [ ] Coordination with organizational security teams documented
